# Digit shaping test fixture

`InterDigits.ttf` contains digits 0–9 from Inter 4.001 (`9221beed3`).
The fixture uses the default variable-axis coordinates, retains the
`tnum` substitution, and omits hinting. The default digits have
proportional advances. Its test family name is Egui Test Digits.

See the [Inter source](https://github.com/rsms/inter/tree/9221beed3)
and the accompanying [SIL Open Font License](Inter-LICENSE.txt).
